# 🍛 Bhalerao's Rasoi

### Authentic Indian Flavors

> **Taste • Tradition • Togetherness**

Bhalerao's Rasoi is a professional multi-page Indian restaurant website created using **HTML only**.

The website represents a traditional Indian restaurant offering authentic Indian cuisine, including biryani, paneer dishes, tandoori specialities, Indian thali, desserts and more.

---

## 🌐 Live Website

🔗 **Live Demo:**  
https://thesumitbhalerao.github.io/Restaurant-Website/index.html

---

## 📌 Project Overview

This project was created as part of my HTML learning journey to practice and demonstrate different HTML tags, attributes, tables, forms, images, hyperlinks and multi-page website navigation.

The website contains **7 interconnected pages** with a consistent restaurant theme.

---

## 📄 Website Pages

| Page | Description |
|---|---|
| 🏠 Home | Restaurant introduction, signature dishes and special offer |
| 🍽️ Menu | Complete Indian food menu with categories and prices |
| 👨‍🍳 About Us | Restaurant story, specialties, mission and chef |
| 📸 Gallery | Indian food and restaurant image gallery |
| 📅 Booking | Table booking form |
| 📞 Contact | Restaurant address, phone, email and location |
| ⭐ Feedback | Customer feedback and rating form |
